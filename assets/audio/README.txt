Background Instrumental Music Directory
========================================

The website already includes an integrated, zero-dependency Web Audio API procedural synthesizer that automatically generates an ambient interstellar soundscape with warm cosmic chord pads and celestial chimes.

If you would like to use your own custom MP3 music file instead:
1. Place your MP3 file in this folder (`assets/audio/`).
2. Rename it to `background.mp3`.
3. Reload the website.

The website's audio engine will automatically detect and play `background.mp3`, while seamlessly retaining all the interactive sound effects (warp whoosh, wax seal break, spotlight click, curtain sweep).
